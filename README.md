# AI-Thinker-ESP32-CAM-WebOS
A Python-based web OS for the AI-Thinker ESP32-CAM. Features include a web desktop, internal flash and SD card file manager, live code editor, NTP time sync, and dynamic web app execution. Manage your hardware and code directly from the browser without repeatedly flashing C++ over serial.

This is AI-Thinker ESP32-CAM Board based Basic PDA
